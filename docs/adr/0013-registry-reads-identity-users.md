# Registry reads Identity users through a lookup in Identity.Contracts

**Context.** ADR 0008 puts the link between a user and a driver on the Registry driver, as a bare user id, and leaves the reverse direction (Registry reading Identity state) to a new ADR when a use case needs it. The driver registry needs it. To link an account, Registry must check that the user exists and has the role `Driver`. The secretariat must see the user name of each driver's account and whether it is disabled, and it must be offered the enabled `Driver` accounts not linked yet. User management in Identity is open to `Admin` only, so the back-office cannot read users from the Identity endpoints.

**Decision.** `Priamus.Trips.Identity.Contracts` exposes a read-only `IUserLookup`, implemented in Identity. Given user ids it returns their user name, role and status, and it lists the user accounts with the role `Driver`. Registry already references `Identity.Contracts` for the policies and the current user, so no new project reference appears. Registry checks the role when a link is saved and enforces "one account, one driver" with a unique index on its own table. It joins user names in memory to the page of drivers it returns. It does not copy any user data into the `registry` schema.

**Why.** The alternatives were worse. Copying user names into Registry would leave a copy to keep in sync when Identity changes, for instance on disable. Opening the Identity user list to the back-office would expose administrator accounts, and would force the frontend to join two APIs. A lookup keeps each schema to its own data and follows the shape of `IDriverLookup`.

**Consequences.** The modules now depend on each other's contracts in both directions: Identity → `Registry.Contracts` (`IDriverLookup`), Registry → `Identity.Contracts` (`IUserLookup`). Neither depends on the other's implementation. A user's role cannot change after creation, so a role checked at link time stays true. A user disabled after being linked stays linked; the driver list shows it as disabled.
